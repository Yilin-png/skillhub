# LPA 审核要点

## 目标

对合伙型私募基金《有限合伙协议》（LPA）做结构化审阅：按模块勾对条款、标出红旗、对照参考文稿给出修改建议。适用于代表 LP、GP 或双边谈判场景；立场不明时先问清审阅立场。

## 组成

```text
lpa-review/
├── SKILL.md                 # 本文件：工作流与输出规范
├── checklist.md             # 12 模块勾对清单 + 红旗
└── references/              # 25 篇专题文稿（按主题分子目录）
    └── INDEX.md
```

## 工作流

```text
- [ ] 1. 确认立场（LP / GP / 双边中立）与基金类型（创投/股权/并购/FOF 等）
- [ ] 2. 收集文本：完整 LPA；若有工商版合伙协议、补充协议、侧函，一并对照
- [ ] 3. 打开 checklist.md，按 12 模块逐项勾对（用户已指定范围则只做该范围）
- [ ] 4. 对勾选中的「关注/红旗」项，打开 references/INDEX.md 对应文稿加深依据
- [ ] 5. 输出审阅备忘（见下方格式）；区分「法定/监管」「市场惯例」「本项目商务选择」
- [ ] 6. 协会规则、地方工商税务以现行口径复核；文稿年代较早处须注明「原文观点，待核现行法」
```

用户只问某一条款（如「关键人士」「管理费」「Clawback」）时：直接定位 checklist 对应模块 + 打开相关 reference，不必跑完全部 12 模块。

## 审阅输出格式

交付一份精炼备忘，默认结构：

```markdown
# LPA 审阅备忘

- 立场：…
- 文本：…（版本/日期）
- 范围：全量 / 仅某某模块

## 结论摘要
（3–7 条最重要发现，按风险优先级）

## 分模块意见
### 模块名
| 条款/位置 | 现状摘录 | 问题/红旗 | 建议 | 依据 |
|-----------|----------|-----------|------|------|
| … | … | … | … | checklist §x / references/… |

## 待向业务确认
（商务取舍、缺失信息、需核对的现行监管口径）
```

要求：
- 摘录短；建议可执行（改哪类表述，而非空泛「建议完善」）。
- 标明立场：对 LP 友好 / 对 GP 友好 / 中性合规。
- 不把文稿中的个人倾向写成法条；引用惯例时写「市场常见做法」。
- 不编造案号、协会窗口指导或未提供的合同条款。

## 关键术语速查

| 术语 | 含义 |
|------|------|
| Capital Call | 按需缴付通知 |
| First / Final Close | 首次 / 最终交割（后续募集） |
| Hurdle / Catch-up / Carry | 门槛收益 / 追赶 / 超额收益分成 |
| Waterfall | 收益分配瀑布 |
| Clawback | 回拨（GP 或 LP） |
| IC | 投资决策委员会 |
| LPAC | 有限合伙人咨询委员会（咨询委员会） |
| Key Person | 关键人士 |
| ROFR | 优先购买权 |
| Parallel / Feeder / Co-Invest | 平行基金 / 联接载体 / 共同投资载体 |

## 边界

- 本 skill **不是**法律意见书模板；输出供内部审阅与谈判准备。
- 文稿来自公开实务连载，可能滞后于最新监管；涉备案、合格投资者、命名、杠杆等结论必须复核现行规则。
- 涉及具体交易文件修改时，保留原文结构与定义体系，避免引入与全文不一致的新术语。
