# 人民币私募基金 LPA 审核清单

> 来源梳理：微信公众号「VC小乒乓的窝」汪澍 · LPA 审核/起草系列（25 篇）
> 用途：审阅合伙型 PE/VC《有限合伙协议》时逐项勾对
> 标注：【审】= 审核系列；【草】= 起草系列
> 详细论述见 `references/` 对应文件

---

## 1. 主体与注册

**核对条款**
- [ ] 基金名称是否符合《企业名称登记管理规定》+《私募投资基金命名指引》（区划+字号+行业+有限合伙）
- [ ] 名称是否禁用保本/稳赢/高收益/无风险/业绩预测等表述；商号是否经合法授权
- [ ] 是否使用「股权投资」或「创业投资」字样；创投税收优惠场景是否刻意保留「创业投资」
- [ ] 注册地工商复杂度、税收政策、与特定 LP（引导基金）迁址关联是否可接受
- [ ] 经营范围是否含「投资咨询」；是否与 GP 经营范围冲突（部分工商窗口风险）
- [ ] GP / 执行事务合伙人是否区分清楚；双 GP 时谁执行事务、谁仅监督
- [ ] GP 出资比例（惯例 ≥1%）、货币出资、合格投资者核验路径（GP=管理人 / 非管理人 / 合伙型 GP 穿透）
- [ ] GP 有权独立决定事项清单是否过宽（名称住所变更、举债担保、委派代表、聘托管/管理人等）
- [ ] 「不正当行为」边界与认定程序是否约定（防除名争议）

**常见陷阱 / 红旗**
- 「股权投资」字样触发地方金监前置审批或最低实缴要求
- 合伙型 GP 合格投资者：仅穿透 vs 自身+穿透双审，协会反馈趋严后者
- Carry 以「投资收益」而非「费用」形式分配（增值税筹划 vs 表述清晰度）
- 工商版合伙协议与完整 LPA 对期限/主体约定不一致

**参考文件**  
`governance/name-and-domicile.md`；`governance/general-partner.md`

## 2. 期限与募集

**核对条款**
- [ ] 是否区分「合伙期限」与「基金期限」；合伙期限是否 ≤ 正常期限+延长期
- [ ] 基金期限届满是否明确列为解散事由（区分后否则不自动清算）
- [ ] 投资期（Investment Period）起算、长度、延长程序（GP / 合伙人会议 / LPAC）
- [ ] 投资期延长是否联动基金总期限，还是仅压缩管理退出期
- [ ] 投资期中止触发：关键人士事件、拟除名 GP、LP 出资违约；托管账户是否同步中止
- [ ] 投资期结束后可投例外：偿债、已决策未交割、追加投资（建议设规模比例上限）、经 LPAC/合伙人会议批准
- [ ] 延长期：总上限、单次长度、次数、决定权归属；延长期管理费是否收取/降费
- [ ] 后续募集期（First Close → Final Close）长度（常见 6–18 个月）及延长程序
- [ ] 最低/最高封闭规模；Final Close 触发（期满/达上限/管理人宣布/关键人士等）
- [ ] 后续投资人资金成本平衡：Capital Call 时点对调 / 定向回款 / 资金成本补偿款 / 项目收益隔离
- [ ] 后续募集期内 GP 可否独立决定入伙；期满后是否须全体同意
- [ ] 备案时点：是否约定 First Close 后备案再投资；后续募集合规窗口（规模/实缴比例）
- [ ] 后续 LP 是否追加管理费；国资 LP 是否要求净值评估 vs 票面入伙

**常见陷阱 / 红旗**
- 合伙期限与基金期限分离但解散条款未挂钩 → LP 失去期限届满强制清算抓手
- 延长期由 GP 单方决定且照常收管理费 → 利益冲突
- 后续募集稀释在先 LP 且无成本补偿
- 工商仍要求全体同意入伙，与 LPA「GP 独立入伙」冲突
- 小规模基金设后续募集期，触及封闭运作/备案限制

**参考文件**  
`governance/term.md`；`governance/subsequent-closing.md`

## 3. 出资与缴付

**核对条款**
- [ ] 出资形式是否锁定货币（协会实务）
- [ ] 出资节奏：一次性 / Capital Call / 按比例分期 / 混合；是否仅投资期内可 Call
- [ ] Capital Call 总额是否 ≤ 认缴；通知要素（金额、时限、账户）是否完备
- [ ] 缴款账户是否为「募集结算资金专用账户」（募集户），而非基本户/托管户混用
- [ ] 出资违约责任菜单：认定程序、权益限缩、违约金、赔偿、罚没/扣留分配、定向减资、强制转让、强制退伙（除名）
- [ ] 违约豁免权（「台阶条款」）归属：GP 单方 or 合伙人会议；是否需守约 LP 同意
- [ ] 各 LP 缴付日是否一致；有无「下轮出资顺序对调」
- [ ] 门槛收益（Hurdle）是否与实缴到账时间挂钩以补偿早出资者
- [ ] 权益/费用/分配按认缴还是实缴；违约 LP 是否仍按认缴分摊费用
- [ ] 是否存在「最后一个出资」条款（引导基金常见）；多名 LP 争后时如何处理
- [ ] 迟延出资豁免违约责任是否仅惠及特定 LP

**常见陷阱 / 红旗**
- Call 可无限期发出，或投资期后仍可 Call（除明确例外）
- GP 豁免违约却不分摊后果 → 守约 LP 承担管理费与机会成本
- 「最后一个出资」+ 违约豁免 → 逆向选择、争后恐先
- 认缴计管理费 + 部分违约 → 守约 LP 代缴违约方管理费（缺管理费 Clawback）

**参考文件**  
`capital/capital-contribution.md`；`capital/contribution-sequence.md`

## 4. 管理费与合伙费用

**核对条款**
- [ ] 管理费定性：必要开支 vs GP 报酬 vs 中间态；用途清单与是否接受审计
- [ ] 价内 or 价外；GP 自有出资是否豁免管理费
- [ ] 公式：计算基数 × 费率 × 时间；基数在投资期（认缴/实缴）与退出期（未退出成本）切换是否清晰
- [ ] 「未退出成本」定义：LP 未收回本金 vs 基金未回收投资成本
- [ ] 费率固定/浮动；投资期后是否降费；延长期/清算期是否收费
- [ ] 起算日（成立日 / First Close）与终止日；支付周期（年/半年/季）与预收制
- [ ] 相机调整：实际管理天数、述职、规模、后续 LP 追收、差异化费率
- [ ] 收取主体是否具备私募基金管理人资格；双 GP 谁收费
- [ ] 合伙费用外延列举是否穷尽；有无过宽兜底条款
- [ ] 开办费上限（额/比例）；募集费用、管理人登记律师费是否排除
- [ ] 投资中介费：成功/失败谁承担；分手费（Break-up Fee）披露与上限
- [ ] 运营费用与管理费边界（场地、差旅是否进基金）
- [ ] 免责补偿（Indemnity）受偿人士范围；责任险是否可列支
- [ ] 资本账户（Capital Account）增减项；费用按认缴/实缴分摊
- [ ] 设立失败、入伙/退伙、投资排除（Excuse）时费用分摊规则
- [ ] 费用 Cap、披露、托管「非投资划款」审核

**常见陷阱 / 红旗**
- 退出期基数用「未退出成本」但 GP 故意延后分配以多收管理费
- 认缴基数 + 违约 LP 退伙 → 守约 LP 多摊管理费且无回拨
- 开办费含募资通道/返佣；失败交易尽调费全推 GP（或反之无上限）
- 合伙费用兜底过宽 → 管理费「双花」
- Carry 以费用形式支付 → 增值税；以超额分配形式 → 丧失税基减项工具

**参考文件**  
`economics/management-fee-1.md`；`management-fee-2.md`；`partnership-expenses-1.md`；`partnership-expenses-2.md`

## 5. 收益分配与回拨（Clawback）

**核对条款**
- [ ] 可供分配收益（Profit）范围：项目回报 / 现金管理收益 / 违约赔偿 / 偶然所得是否分池
- [ ] 计算 Carry 的收益是否为净收益（Net Profit，扣成本费用偿债后）；税前税后口径
- [ ] By Deal（美国模式）还是 By Fund（欧洲模式 / 本金优先返还）；By Deal 是否配 Clawback
- [ ] 是否设门槛收益（Hurdle）及 Waterfall：还本 → Hurdle → Catch-up → 二八
- [ ] Catch-up 比例是否标准（门槛收益的 25%，使 GP 最终拿满超额的 20%）
- [ ] 用「整体超门槛时 Carry = 超额×20%」反测 Waterfall 是否写歪
- [ ] GP 出资是否独立计收益；费用分摊是否与 LP 同股同权
- [ ] Partner-by-Partner vs All Partners；「二八」中 80% 是否含 GP 本金权益
- [ ] GP Clawback：触发时点（亏损时/清算时）、上限（已收 Carry/管理费）、Escrow、ManagerCo Guarantee
- [ ] LP Clawback：场景（复杂 Carry 调整、税务补缴、偿债）、时限、金额上限（取回财产/认缴孰低）
- [ ] 基金债务/免责补偿外延是否借 LP Clawback 无限放大
- [ ] 回拨是否考虑已纳税成本

**常见陷阱 / 红旗**
- By Deal 无 Clawback → 总亏仍拿 Carry
- Waterfall 缺 Catch-up 或比例错 → GP 少拿/多拿
- All Partners 误写成「20% GP + 80% 仅 LP」吞掉 GP 本金对应收益
- LP Clawback 用于填 GP 无限责任 + 宽泛 Indemnity → LP「落袋不安」
- 母基金/引导基金客观上无法履行 LP Clawback

**参考文件**  
`economics/distribution.md`；`drafting/clawback.md`

## 6. 投资范围与工具

**核对条款**
- [ ] 基金划型（股权/创投/并购/定增/FOF 等）与「八二原则」是否匹配
- [ ] 法定限制清单（引导基金/产业基金办法等）是否落入 LPA 禁止项
- [ ] 约定限制：行业、地域、单笔比例、投资形式、控股目的、再投资、境外等
- [ ] 债权/过桥/可转债（附转股债权）比例上限（常见 ≤20%）
- [ ] 「可转债」定性：交易所非公开可转债 vs 附转股条件债权合同；后者按债权控比例
- [ ] 是否禁止参与上市公司公开发行可转债
- [ ] 投资范围重大变更：合伙人会议/LPAC 审议 + 信披 + 必要时重新适当性

**常见陷阱 / 红旗**
- 名称/备案类型与实际策略不符（创投投地产等）
- 「可转债」实为放贷：转股权在债务人、苛刻转股条件 → 伪私募风险
- 禁止项照抄模板却与本基金策略（并购、夹层）矛盾

**参考文件**  
`investment/investment-scope.md`；`investment/convertible-debt.md`

## 7. 治理三会（IC / LPAC / 合伙人会议）

**核对条款**
- [ ] IC（Investment Committee）定位：GP 内设 vs 基金内设；最终决策权归属
- [ ] IC 权限：投资、重大投后、主动退出；被动分红退出是否豁免
- [ ] IC 构成：纯 GP / +专家 / +LP / 混合；观察员（Observer）有知情无表决
- [ ] 议事规则：多数决；大额/关联交易是否全票；银弹（Silver Bullet）次数与责任挂钩
- [ ] IC 名单披露/变更程序；GP 委派委员与关键人士联动
- [ ] LPAC（Advisory Committee）：决策权 or 建议权；有权事项是否列举（关联交易、超限投资、期限延长、关键人士、托管审计聘任）
- [ ] LPAC 席位：出资门槛、机构性质、人数（3–7 单数）、观察员
- [ ] LPAC 程序：召集、提前材料、决议存档；审议侧重公允性/风控而非商业实质
- [ ] 合伙人会议权限：法定事项（修订协议、出质、入伙退伙、除名、解散、执行事务合伙人更换等）哪些改由 GP/LPAC
- [ ] 更换管理人/托管人、调整报酬、举债担保、非现金分配、费用预算是否进合伙人会议
- [ ] 召集：召集权人、通知期限、出席门槛、资本多数决比例（过半数/2/3/全体）

**常见陷阱 / 红旗**
- LP 进 IC 有表决权 → 执行合伙事务风险、责任不清
- 有决策权 LPAC 对商业实质投票 → 事后追责争议
- 法定须「全体一致」事项被改成 GP 单决且无例外说明
- IC 议事规则仅「内部制度」不向 LP 备案

**参考文件**  
`governance/ic.md`；`lpac.md`；`partners-meeting.md`

## 8. 关键人士（Key Person）

**核对条款**
- [ ] 关键人士认定：实际控制 / 基金运营决策 / IC 影响力 / 策略执行；是否自然人
- [ ] 服务内容是否具体：整体运作、投资决策、组合管理、退出（非仅「为 GP 服务」）
- [ ] 服务期限：仅投资期 vs 全存续期；持续服务（连续天数上限）与诚信要求
- [ ] 精力分配：投资期结束前不得为其他基金服务；同策略基金/平行载体豁免是否合理
- [ ] Key Person Trigger：行为能力丧失、累计无法服务天数、离职/离 IC、严重利冲；多级人数触发规则
- [ ] 触发后果：暂停投资/Call → 替任人选经 LP/LPAC 评估 → 接受则恢复并延长投资期；拒绝则结束投资期
- [ ] 额外救济：管理费/Carry 调整、新增管理人员费用从管理费扣减、除名/替任 GP
- [ ] For Cause（欺诈、违信义、违法）是否单独约定
- [ ] 一般性事件是否强制信披

**常见陷阱 / 红旗**
- 关键人士仅为募资「站台大佬」，无实质投入精力
- 服务对象写成 GP/关联方而非本基金
- 触发仅限投资期，退出期关键人出走无约束
- 触发后果过重或过轻；无暂停投资缓冲

**参考文件**  
`governance/key-person.md`

## 9. 份额转让与优先购买权（ROFR）

**核对条款**
- [ ] GP 对外转让：其他合伙人一致同意 + 法定优先购买权；协议是否排除/扩展
- [ ] LP 对外转让：提前 30 日通知（法定，不宜缩短）；是否另需 GP/LPAC/合伙人会议同意
- [ ] 关联方转让、内部转让是否豁免同意/ROFR
- [ ] 受让方合格投资者、人数上限、三类股东、国资成分、负面清单审查
- [ ] ROFR 程序：通知内容、行权期（建议≥30 日）、默示放弃、除斥（知悉 30 日/变更登记 1 年）
- [ ] 「同等条件」：数量、价格、支付方式及期限
- [ ] 多优先方：分级 or 按出资比例分摊
- [ ] 优先方行权后转让方反悔：强制成交 or 赔偿
- [ ] 受让方取得合伙人身份是否须修订 LPA
- [ ] GP 收益权/管理权拆分转让是否视同份额转让
- [ ] 强制转让价格机制（违约/除名场景）：成本/评估/折扣；Carry 结算
- [ ] 信披与协会系统变更

**常见陷阱 / 红旗**
- 绝对禁止转让 → 司法上可能被认定过度限制
- LP 对外转让未设 ROFR 程序细节 → 「有权无用」
- 损害优先购买权仅诉无效而不主张购买 → 法院可能不支持
- LP 承接 GP 份额引发身份混同的工商不确定性

**参考文件**  
`transfer/interest-transfer.md`；`transfer/rofr.md`

## 10. 除名与退伙

**核对条款**
- [ ] 法定事由：未履行出资；故意/重大过失致损；执行事务不正当；约定事由
- [ ] 「未履行出资」是否明确含「未按期足额」（否则可能仅补缴+违约）
- [ ] 「故意/重大过失」「不正当行为」「造成损失」是否有可操作定义/第三方认定
- [ ] 约定事由：资本结构阻碍 IPO/资质、重大违约、给定期限损失等
- [ ] 程序：其他合伙人一致同意决议 → 书面通知 → 接到之日起生效；30 日内起诉异议
- [ ] 协议将「一致同意」降为 GP+比例 LP 是否构成效力性强制规范风险
- [ ] 从严前置（仲裁/诉讼认定事由）是否保留
- [ ] 关联方/利益相关方表决权是否回避
- [ ] 两人合伙是否排除除名；除名后人数合规与解散衔接
- [ ] 除名生效后退伙结算（财产取回、债务责任）规则
- [ ] 执行事务合伙人「去职」与「合伙人除名」是否区分

**常见陷阱 / 红旗**
- 除名事由模糊 → 诉讼中决议无效（举证「损失」失败）
- 未书面通知 → 除名不生效
- 压缩「一致同意」→ 决议被判无效
- 约定仲裁排除「除名无效之诉」→ 法院可能不受理排除

**参考文件**  
`drafting/expulsion-withdrawal.md`；（关联）`capital/capital-contribution.md`；`governance/general-partner.md`

## 11. 平行 / 联接 / 共同投资

**核对条款 — 平行基金（Parallel Fund）**
- [ ] 是否披露平行架构；同管理人/同团队/同策略/同期是否构成狭义平行
- [ ] 平行投资策略：机会按可投规模比例分配；投资与退出条件对等
- [ ] 基金合同投资者权利是否实质相同；规模限制/单笔限额是否合并计算
- [ ] 平行策略执行情况定期信披

**核对条款 — 联接载体（Feeder）**
- [ ] 是否由主基金 GP/关联方发起管理；唯一目的投资主基金（Master）
- [ ] Feeder LP 权利穿透：LPAC 席位、主基金表决按穿透出资计入
- [ ] Feeder 层 No Fee / No Carry；GP 出资与主基金合并 ≥1%
- [ ] Feeder 费用由主基金承担是否对全体 LP 不公；穿透人数 ≤200、合格投资者
- [ ] 是否备案；伞形规避 50 人限制的工商风险

**核对条款 — 共同投资（Co-Invest）/ 替代投资实体（AIV）**
- [ ] 是否由本基金 GP/关联方控制；唯一目的投特定标的
- [ ] 受益人是否限本基金及本 LP；外部投资者是否触发备案与额度分配利冲
- [ ] GP 对 Co-Invest 是否额外收费；本基金部分通常不重复收费
- [ ] SPV 间接投资：强制托管、资金流监控、特殊风险揭示
- [ ] 维持费用入本基金费用的边界；滥用 SPV 规避托管/信披

**常见陷阱 / 红旗**
- 「平行」豁免利冲但无比例分配/对等退出规则
- Feeder 收双层管理费；权利不穿透
- Co-Invest 引入外部人抢额度；财产出托管户失控
- 定义混淆 Parallel / Feeder / Co-Invest / SPV / SLP

**参考文件**  
`vehicles/parallel-fund.md`；`feeder.md`；`co-invest.md`

## 12. 融资性活动

**核对条款**
- [ ] 基金层面举债（发债/贷款）：原则禁止 or 负债比上限（资管新规 200%，建议更严如 150%）
- [ ] 举债/担保是否须合伙人会议或 LPAC 批准（限制 GP 单决）
- [ ] 过桥贷款：未回收余额比例（建议 ≤10%–20%）；对象限已投企业；用途临时流动性；期限 ≤12 月；优先委托贷款/信托贷款
- [ ] 禁止经常性、经营性民间借贷（伪私募红线）
- [ ] 对外担保：对象限已投企业；担保额相对基金规模/该项目投资额/负债比上限
- [ ] 可转债/债权工具与融资条款交叉引用比例限制
- [ ] 负债、过桥、担保的风险揭示与定期信披

**常见陷阱 / 红旗**
- GP 单方可举债担保 → 无限责任与 LP Clawback 压力传导
- 过桥常态化、高息、对象不限 → 冲突业务/伪私募
- 为非被投第三方担保
- 并购基金杠杆需求与普通创投模板「一刀切禁止」未区分说明

**参考文件**  
`investment/financing-activities.md`；（关联）`convertible-debt.md`；`investment-scope.md`
